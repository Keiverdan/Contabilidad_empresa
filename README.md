# 📚 La Contabilidad de Elohim

Sistema contable 100% venezolano adaptado a las normas **VEN-NIF**, **SENIAT** y **LOTTT**.

## ✨ Características

- 📊 Plan de cuentas VEN-NIF
- 💱 Tasa BCV con histórico
- 👥 Clientes y proveedores (personas naturales y jurídicas con RIF validado)
- 📦 Productos e inventario con valorización
- 🛒 Compras con retenciones IVA/ISLR
- 💰 Ventas y servicios con asientos automáticos
- 💼 Nómina completa (IVSS, RPE, FAOV, INCE, Paro Forzoso) + Nómina rápida y liquidaciones
- 📈 Presupuestos automatizados
- 📒 Libro Diario, Mayor, Comprobación, Inventario y Auxiliares
- 🏛️ Libros electrónicos SENIAT (Compras y Ventas) con export TXT
- 📊 Análisis de ganancias y estructura de compras
- 🎓 Tutorial interactivo + Glosario de 70+ términos
- 💾 Persistencia en localStorage + respaldo JSON
- 📱 Diseño responsive (móvil, tablet, escritorio)
